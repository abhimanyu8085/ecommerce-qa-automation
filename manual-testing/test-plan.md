# Test Plan

## Objective
Validate critical e-commerce functionality and ensure core customer journeys work as expected.

## Scope
Login, product listing, cart, checkout and logout.

## Test Types
Functional, UI, positive/negative, smoke and regression testing.

## Environment
Chrome desktop browser; public SauceDemo test environment.

## Entry Criteria
Application is accessible and test credentials are available.

## Exit Criteria
Critical scenarios executed; blocking/high-severity defects documented; automated regression suite executable.

## Risks
Public demo application behavior may change independently of this project.
